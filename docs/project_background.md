# 项目背景

项目名称：
基于深度学习的钢铁表面缺陷智能检测系统。


## 项目目标

利用深度学习方法，对钢铁表面缺陷图片进行自动分类。

数据集：
NEU surface defect dataset。

任务：
六类钢铁表面缺陷分类。


## 当前技术路线

第一阶段：

使用自己构建的CNN模型完成基础图像分类。

目的：
理解深度学习训练完整流程。


第二阶段：

使用ResNet18迁移学习。

目的：
学习工业视觉中常用的预训练模型方法。


第三阶段：

模型评估：

包括：
- 测试集准确率
- 混淆矩阵


第四阶段：

模型解释：

使用Grad-CAM分析模型关注区域。


第五阶段：

计划：

使用Streamlit开发网页应用。

实现：
用户上传图片，
模型自动预测缺陷类型，
显示预测结果和可解释热力图。


## 当前项目文件

主要文件：

train.py:
训练CNN模型。

train_resnet.py:
训练ResNet18迁移学习模型。

test.py:
测试CNN。

test_resnet.py:
测试ResNet。

predict.py:
单张图片预测。

confusion_matrix.py:
分析分类错误。

gradcam.py:
生成模型关注区域。

通过这个项目学习：

- Python工程结构

- CNN
